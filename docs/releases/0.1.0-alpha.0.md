# 0.1.0-alpha.0 release notes

> Published to npm under the `alpha` dist-tag on 2026-08-19. The matching GitHub release is a
> prerelease, not a stable release.

## First Alpha scope

This release adds one `openai-codex` provider route to DeepSeek Harness and authenticates it through
a package-owned ChatGPT/Codex OAuth login. DSH continues to own the agent loop, tools, approvals,
sessions, attachments, compaction, persistence, cancellation, and recovery.

The package includes:

- provider-owned model metadata from the pinned pi-ai catalog;
- `login`, `logout`, `status`, `doctor`, and `version` commands;
- an owner-only, symlink-rejecting, atomically replaced credential document on supported POSIX
  systems;
- request-scoped OAuth refresh and explicit rejection of ambient API-key fallback;
- exact runtime checks and a packed-install release gate.

## Verified compatibility

- DeepSeek Harness `0.1.0-rc.7`
- `@deepseek-ai/cordis` `4.0.1`
- `@earendil-works/pi-ai` `0.82.1`
- Node.js `^22.19.0 || ^24.0.0 || ^26.0.0`
- Linux and macOS

## Security and privacy

The package stores OAuth credentials as plaintext protected by OS filesystem permissions, not
encryption. It never reuses Codex CLI or ChatGPT Desktop credentials and does not support OpenAI
Platform API keys. `status` and `doctor` are offline and omit account and credential data.

Report suspected vulnerabilities through the private process in `SECURITY.md`. Never include
credentials, authorization data, account identifiers, local paths, environment dumps, or model
conversations.
