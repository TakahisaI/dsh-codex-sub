# 0.1.0-alpha.1 release notes

> Published to npm under the `alpha` dist-tag on 2026-08-19. The matching GitHub release is a
> prerelease, not a stable release.

## Release-only scope

This release proves the post-bootstrap stage-only npm Trusted Publishing path. It does not
change the provider route, model catalog, OAuth behavior, credential persistence, CLI schemas, or
runtime compatibility.

It adds:

- the final secret-free exact-artifact record for `0.1.0-alpha.0`;
- OIDC staging of the one verified workflow artifact for separate maintainer approval;
- fail-closed serialization of manual release runs without in-progress cancellation;
- the post-bootstrap npm `alpha` and `latest` dist-tag policy.
